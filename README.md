# МДК.05.01 — практические работы (Next.js)

Проект Next.js (App Router, TypeScript, Tailwind), выполненный на ПЗ №1 и ПЗ №2.

## ПЗ №1. Введение в Next.js
- главная страница (`app/page.tsx`)
- страница `/about` (`app/about/page.tsx`)
- ссылка между страницами через `next/link`

## ПЗ №2. Компоненты и навигация
- компонент `components/Card.tsx` с пропсами
- раздел `/posts` со списком постов и общим `layout.tsx`
- динамический маршрут `/posts/[id]`
- ссылки из списка постов на отдельные посты

## Запуск
```
npm install
npm run dev
```
